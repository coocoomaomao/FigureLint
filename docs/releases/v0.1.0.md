# FigureLint v0.1.0

The first public alpha release of FigureLint: **ESLint for academic figures.**

FigureLint helps researchers and students catch reproducible technical figure problems before submission.

## Highlights

- PNG and JPEG inspection
- SVG technical inspection
- PDF technical inspection
- recursive folder checks
- configurable thresholds
- named preset engine
- source-verified Nature preset
- CI-friendly exit codes and strict mode

## Raster checks

FigureLint can report:

- unreadable image files
- missing / low DPI metadata
- suspiciously small raster dimensions
- alpha transparency
- JPEG lossy-format usage

## SVG checks

FigureLint can report:

- malformed SVG files
- missing editable text
- unresolved font sizes
- text below / above configured size ranges
- strokes below / above configured width ranges
- conservative Nature panel-label checks
- explicit font-family consistency and preference guidance
- simple CSS / inline-style resolution

## PDF checks

FigureLint can report:

- unreadable / password-protected PDFs
- empty or multi-page PDFs
- unusual page dimensions
- missing editable text
- unembedded or unresolved fonts
- low effective DPI for embedded raster images
- raster soft masks / alpha channels

## Presets

Built-in convenience profiles:

- `default`
- `high-resolution`
- `presentation`
- `journal-generic`

Source-verified publisher profile:

- `nature`

The Nature profile stores its official source metadata and deliberately avoids presenting unsourced FigureLint convenience thresholds as Nature requirements.

## Quick start

After publication to PyPI:

~~~bash
pip install figurelint
figurelint check figure.svg
figurelint check figures/ --preset nature
~~~

## Status

FigureLint v0.1.0 is an alpha release. It is designed to flag deterministic technical properties and clearly document limitations rather than claim that every submission rule can be inferred automatically.
